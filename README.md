# Welcome To JOSH


### Josh is an interface for interacting and talking to local AI agents
### Josh was created by me (Caro122) as a personal project to help make an agent like chatbot that can interact with your computer and that can talk to you


## Requirements/Setup:
For JOSH to work properly, you will need to install VOSK Speech recognition and drag that folder to the same folder the Audio To Text To Speech.py is located
VOSK Direct Download: https://alphacephei.com/vosk/models/vosk-model-en-us-0.42-gigaspeech.zip

You will Also need to run it through ollama.
Just run the setup script and ollama should automatically install along with the required models for this program to work
